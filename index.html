Documentos

Manuales, fichas técnicas y menú de la casa. Aquí también está la guía para subir cada semana.

Subir documento

El archivo se guarda en Supabase Storage (bucket "documentos") y queda disponible para ver y descargar desde la app. Antes de subir por primera vez, corre el archivo Supabase-Cantaros-Documentos-Storage.sql en el SQL Editor de Supabase.

Guía de carga semanal

Todo se divide por semana: cada semana se identifica por su lunes (week_start). Hay dos formas de subir cada cosa; elige la que te acomode.

📄 Ventas (reporte de Soft Restaurant)

  1. Opción A — pegar en Supabase: en el panel de Supabase abre Table Editor → ventas_pos_import → Insert → Paste rows y pega el CSV del reporte tal cual (columnas CLAVE, DESCRIPCION, GRUPO, PRECIO, CANTIDAD, VENTA_TOTAL, COSTO, COSTO_TOTAL, VENTA_COSTO, PRECIO_DE_VENTA, PRECIO_DE_CATALOGO, VENTA_TOTAL_PRECIO_CATALOGO, TASA_IVA), con la semana puesta en week_start. La app cruza con el catálogo y calcula costo y margen.
  2. Opción B — subir el archivo en esta app: en Captura semanal → Subir reporte de Soft Restaurant (Excel o CSV), elige la semana y el archivo Excel (.xlsx) o CSV. La app guarda el staging y genera las ventas con costo automáticamente.
  3. Si se pega dos veces la misma semana, la base la rechaza (unique por semana + clave). Para corregirla, se borra esa semana y se vuelve a subir.

🍺 Inventario de barra y cocina

  1. Opción A — pegar en Supabase: en Table Editor → inventory_weekly (barra) o inventory_cocina (cocina), pega las filas de la semana. Solo captura Inicial, Compras, Almacén, Display, Barra y Venta; el resto (total, diferencia, perdido, sobrante y sus $) se calcula solo.
  2. Opción B — subir el archivo en esta app: en Captura semanal → Subir conteo de inventario (Excel o CSV), elige el área, la semana y el archivo Excel (.xls/.xlsx) o CSV de la semana. El inventario ya no se captura a mano: siempre se sube el archivo.
  3. El sobrante también vale dinero: esta semana el sobrante de barra es $5,592, más que el faltante ($2,253). Revisa los sobrantes grandes (Miller Caguama +59, Tecate Roja Media +58): pueden ser errores de captura o compras no registradas.

🧾 Ventas por mesero, cortesías y descuentos

  1. Se capturan aquí mismo, en Captura semanal → Venta por mesero. El reporte del POS no trae mesero, turno ni folio, así que esta captura es la única fuente de esas dimensiones.
  2. Las cortesías se marcan con la casilla y se guardan en $0; los descuentos se anotan en pesos en el mismo renglón.

📅 Horarios del staff

  1. Antes de usar la vista Horarios por primera vez, corre el archivo Supabase-Cantaros-Horarios.sql en Supabase → SQL Editor (crea las tablas staff, horarios y eventos y siembra los 18 nombres del personal).
  2. Después expón las tres tablas en Supabase → Integrations → Data API (o activa "Default privileges for new entities") para que la app las pueda leer y escribir.
  3. Los turnos se escriben directo en la tabla, libres: 11-CL (entrada a cierre), 11:00-20:00 (entrada y salida), OFF (descanso), F (falta); se guardan solos al cambiar de celda. Si una semana no tiene turnos, las celdas quedan vacías: nunca se copia otra semana.
  4. Los eventos especiales y reservaciones grandes se agregan en la misma vista y aparecen en la columna de su día. Arriba de la tabla están los botones Ver imagen (muestra la tabla lista para guardar o compartir por WhatsApp), Exportar Excel (descarga el .xlsx de la semana) y Exportar PDF (abre la vista para imprimir o guardar como PDF).

📚 Documentos

  1. Antes de subir el primer archivo, corre el archivo Supabase-Cantaros-Documentos-Storage.sql en Supabase → SQL Editor (crea el bucket público documentos y sus políticas, y agrega las columnas file_url y file_path a la tabla documents).
  2. Después sube el archivo aquí mismo, en Documentos → Subir documento (archivo + título + categoría + nota). Cada documento muestra los botones Ver (abre el archivo en una pestaña) y Descargar.
  3. Si la subida falla diciendo que el bucket no existe, es que falta el paso 1.
